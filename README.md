# ARTENIA – Frontend MVP completo

Este proyecto es un esqueleto funcional del frontend independiente de ARTENIA:

- React + Vite + TypeScript
- Mapa Mapbox 3D básico
- Estructura preparada para módulos: artesanos, rutas, lugares, roles, auth…

## Arranque rápido

1. Descomprime el .zip
2. Entra en la carpeta:

   ```bash
   cd artenia-frontend
   ```

3. Copia el `.env.example` a `.env`:

   ```bash
   cp .env.example .env
   ```

4. Instala dependencias:

   ```bash
   npm install
   ```

5. Arranca el proyecto:

   ```bash
   npm run dev
   ```

6. Abre la URL que te da Vite (normalmente http://localhost:5173)

Verás:

- Una Home sencilla
- Una página de Mapa con el Mapbox 3D de Alicante
- Estructura de carpetas lista para seguir construyendo (módulos, páginas, supabase, etc.)
